# Graph-based Learning-to-Dispatch for Dynamic Job Shop Scheduling
## with Topology Generalization

A deep learning approach for job shop scheduling that learns to dispatch operations
using graph neural networks, with zero-shot generalization across shop topologies.

## Abstract

Job shop scheduling (JSS) is a fundamental combinatorial optimization problem in
manufacturing systems. While dispatching rules such as Shortest Processing Time (SPT)
remain the dominant industrial practice due to their interpretability and speed,
no single rule performs consistently across diverse shop configurations. We propose
a Graph Neural Network (GNN) learning-to-dispatch (L2D) framework that learns
state-dependent operation selection from optimal trajectories generated by CP-SAT.
The trained policy dynamically combines dispatching principles and generalizes to
unseen topologies without retraining. Experiments on 6x5 job shop instances show
the learned policy improves makespan by 10.5% over SPT (127.5 vs 142.4) and
maintains consistent advantages across zero-shot transfers to 5x5, 8x5, and 6x8
configurations. The proposed approach requires no hand-crafted features and provides
an interpretable, deployable alternative to pure optimization solvers for real-time
manufacturing scheduling.

## 1. Introduction

Manufacturing scheduling determines how jobs are sequenced on shared machines.
Dynamic job shops---where orders arrive stochastically and machine availability varies
---are common in flexible manufacturing systems. Exact methods (mixed-integer
programming, constraint programming) provide optimal schedules but scale poorly to
real-time decisions. Dispatching rules (SPT, LPT, MWKR, LWKR, FIFO) are fast and
interpretable but no single rule dominates across all states and topologies.

Recent advances in graph neural networks and reinforcement learning have enabled
"learning to dispatch" (L2D): train a policy to select operations at each decision
step, supervised by optimal or expert trajectories. Existing L2D methods typically
assume a fixed shop topology (e.g., 6 jobs x 5 machines) and retrain when topology
changes. We address this gap by proposing a padded, topology-agnostic GNN policy that
transfers zero-shot across shop sizes.

## 2. Method

### 2.1 Job Shop Environment

We model a job shop as a deterministic scheduling problem: each job j has an ordered
sequence of operations, each requiring a specific machine with processing time
p_{j,m}. The environment advances time only when no operation can start, allowing
concurrent machine usage. State features per job include: current operation duration,
remaining work, total work, and progress.

### 2.2 GNN Policy

A graph attention network (GAT) encodes job-level states into embeddings. A policy
head scores available operations; the highest-scoring available operation is selected
at each decision step.

### 2.3 Expert Trajectories via CP-SAT

We use Google OR-Tools CP-SAT to solve each training instance to optimality. The
optimal schedule induces expert actions: at each state, select the available operation
whose optimal start time is earliest. This provides strong supervision without
heuristic noise.

### 2.4 Topology Generalization

We zero-pad job features to a maximum size (10 jobs) and mask unavailable jobs during
selection. This enables a single policy to operate on 5, 6, or 8-job instances
without retraining.

## 3. Experiments

### 3.1 Setup

- Training: 80 random 6x5 instances (processing times U[1,20])
- Expert: CP-SAT optimal schedules (5s time limit)
- Model: 2-layer GAT, hidden 64, MLP policy head
- Training: cross-entropy, Adam lr=1e-3, 50 epochs, batch 64
- Evaluation: 20 held-out instances per configuration

### 3.2 Results

| Configuration | Agent | SPT | Best-of-5 | Agent vs SPT |
|--------------|-------|-----|-----------|--------------|
| Same (6x5)   | 127.5 | 142.4 | 124.2    | **+10.5%**   |
| Fewer jobs (5x5) | 122.5 | 123.8 | 117.8 | **+1.0%**   |
| More jobs (8x5)  | 164.4 | 184.1 | 156.2 | **+10.7%**  |
| More machines (6x8) | 179.5 | 201.4 | 173.7 | **+10.9%** |

The learned policy outperforms SPT across all configurations, including zero-shot
topology transfers. It approaches the best-of-5 heuristic oracle while remaining a
single lightweight policy.

### 3.3 Dynamic Arrival Scenario

To evaluate deployment robustness, we extend the environment with stochastic job
arrival times (exponential distribution, scale = 50). The static-trained policy is
evaluated zero-shot without any adaptation:

| Method | Avg Makespan | vs SPT |
|--------|-------------|--------|
| GNN-L2D (static-trained) | 191.2 | **+12.3%** |
| SPT | 218.1 | - |
| FIFO | 196.5 | +9.9% |

The policy trained purely on static instances outperforms both SPT and FIFO in
dynamic arrival scenarios, demonstrating that learned dispatch policies capture
state-dependent priorities that transfer across scheduling contexts.

## 4. Conclusion

We present a GNN-based learning-to-dispatch framework for job shop scheduling with
zero-shot topology generalization. The policy consistently improves over SPT and
transfers across shop sizes without retraining. Future work includes dynamic arrivals,
multi-machine flexible routing, and integration with reinforcement learning for
online adaptation.
